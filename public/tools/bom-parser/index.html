Chưa có dữ liệu. Vui lòng upload file BOM.

Hướng dẫn nhanh

  • File Excel cần có header đúng thứ tự (cột 1 = index, cột 2 = ass_name, ...).
  • Dòng bắt đầu dữ liệu có thể điều chỉnh thông qua ô “Bỏ qua dòng đầu”.
  • Hệ thống tự nhận dạng dòng cha (có index) và thêm các dòng con vào mảng children.
  • Các giá trị số sẽ được chuẩn hóa về dạng Number; ô trống sẽ trở thành null.
  • Có thể tải JSON về máy để nhập vào hệ thống điều phối.

Lưu ý: Công cụ chạy trong trình duyệt, không gửi dữ liệu ra ngoài. Với file rất lớn, quá trình xử lý có thể mất vài giây – hãy giữ cửa sổ trình duyệt mở tới khi hoàn tất.
